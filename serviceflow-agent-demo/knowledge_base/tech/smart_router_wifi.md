# SmartRouter X1 WiFi 连接与联网排查

SmartRouter X1 支持 2.4G 和 5G WiFi。首次使用时，请先接通电源，等待指示灯从白色慢闪进入蓝色呼吸状态，再打开 ServiceFlow App 进行配网。

## 连接步骤

1. 打开 ServiceFlow App，进入设备添加页面。
2. 选择 SmartRouter X1，确认手机已连接家庭 WiFi。
3. 输入 WiFi 密码，保持手机距离设备 2 米内。
4. 等待设备指示灯变为白色常亮，表示连接成功。

## 指示灯状态

- 蓝色呼吸：等待配置。
- 白色常亮：联网成功。
- 黄色慢闪：网络信号弱或 DNS 解析失败。
- 红色快闪：配网失败或设备重启中。

## 无法联网排查

先确认路由器供电正常，再检查 WiFi 密码是否正确。若使用 5G WiFi 无法连接，可切换到 2.4G WiFi 重试。仍无法联网时，长按复位键 8 秒恢复出厂设置，再重新配置。
